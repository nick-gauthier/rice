# Derived Data Files

This directory contains intermediate data files generated by `preprocessing.qmd`. These files are used by `main.qmd` and `supplementary_materials.qmd` to produce the manuscript figures and analyses.

## File Descriptions

### Climate Data

| File | Size | Generated By | Used By | Description |
|------|------|--------------|---------|-------------|
| `chelsa_asia.rds` | 1.9 MB | preprocessing.qmd | main.qmd | CHELSA V2.1 climate data cropped to Asia and downsampled for efficient plotting. Contains mean annual temperature, max temp of warmest month, and max temp of warmest quarter (1981-2010). |
| `chelsa_world_downsampled.rds` | 20 MB | preprocessing.qmd | main.qmd | CHELSA V2.1 climate data for the world, downsampled for supplementary figures. |
| `trace_ts.rds` | 4.0 KB | preprocessing.qmd | main.qmd | Area-averaged time series of CHELSA-TraCE21k temperature variables over Asia for the past 12,000 years. |
| `erb_rast.rds` | 24 MB | preprocessing.qmd | main.qmd | Holocene temperature reconstruction from Erb et al. 2022, cropped to Asia with ensemble statistics. |
| `lgmr_rast.rds` | 1.3 MB | preprocessing.qmd | main.qmd | Last Glacial Maximum Reanalysis (LGMR) temperature data from Osman et al. 2021, cropped to Asia. |
| `cmip6_data.rds` | 21 MB | preprocessing.qmd | main.qmd | Downsampled CMIP6 future climate projections (2071-2100) for Asia. Contains 5 models x 3 SSP scenarios x 3 temperature variables. |

## Data Sources

### Contemporary Climate (CHELSA V2.1)
- **Source**: https://chelsa-climate.org/
- **Reference**: Karger et al. 2017, 2018; Brun et al. 2022
- **Period**: 1981-2010
- **Resolution**: Aggregated from 1km to 5-10km

### Paleoclimate (CHELSA-TraCE21k)
- **Source**: https://chelsa-climate.org/chelsa-trace21k/
- **Reference**: Karger et al. 2023; He et al. 2011
- **Period**: Last 12,000 years (100-year intervals)
- **Note**: Full dataset ~120 GB, not included in repository. Only extracted values at archaeological sites are stored.

### Future Climate (CMIP6/ISIMIP3b)
- **Source**: https://www.isimip.org/
- **Models**: GFDL, IPSL, MPI, MRI, UKESM
- **Scenarios**: SSP1-2.6, SSP3-7.0, SSP5-8.5
- **Period**: 2071-2100
- **Resolution**: Downscaled to CHELSA grid

### Rice Occurrence Data
- **IRRI**: Nelson & Gumma 2015 (satellite, 500m, Asia)
- **Monfreda**: Monfreda et al. 2008 (census/satellite hybrid, 10km, global)
- **GBIF/Herbaria**: Yang et al. 2022, Civán & Brown 2018, Gutaker et al. 2020

### Archaeological Data
- **Sources**: Guedes & Bocinsky 2018, Long et al. 2022, Silva et al. 2015, Crema et al. 2022
- **Calibration**: IntCal20 (northern hemisphere), SHCal20 (southern hemisphere)

## Reproducibility Notes

1. All intermediate files can be regenerated by running `preprocessing.qmd`
2. The main manuscript (`main.qmd`) reads these files but does not modify them
3. File sizes are approximate and may vary with R version and compression
4. Random seeds are set in preprocessing.qmd for reproducible bootstrapping (seed = 5678) and spatial sampling (seed = 1234)

## File Formats

All `.rds` files are R data serialization format (saveRDS/readRDS). They can be read in R using:
```r
data <- readRDS("filename.rds")
```

`.RData` files contain multiple R objects and can be loaded using:
```r
load("filename.RData")
```
